# MONARCH Barbershop

A premium responsive barbershop website concept built with HTML, CSS, and JavaScript.

## Live Demo

https://dashing-monstera-67d528.netlify.app

## Features

- Responsive layout
- Premium dark visual design
- Fixed navigation
- Services section
- Barber profiles
- Image gallery
- Pricing section
- Booking form
- Scroll reveal animations
- Mobile-friendly layout

## Built With

- HTML5
- CSS3
- JavaScript

## Project Goal

This project was created as a realistic small-business website concept for a modern barbershop. The goal was to build a polished, client-ready front-end experience with clear calls to action and a simple booking flow.
